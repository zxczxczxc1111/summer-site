# Как я провёл это лето

Адаптивная страница по [макету Figma](https://www.figma.com/design/2pnF0iruTubT31eBA98oin/siteGG). Реализована на чистых HTML, CSS и JavaScript с понятными именами классов по БЭМ (например, `nachalo__foto`, `dekor__ochki_foto`). Откройте `index.html` в браузере. Кнопка «СМОТРЕТЬ» прокручивает страницу к разделу о летней деятельности. Переключатель темы сохраняет выбор в `localStorage`.

## Сверка с макетом

- Фотографии и декор взяты из экспортов Figma. Пальмы, гамак и очки сохранены отдельными SVG со встроенной прозрачностью и размещены по координатам макета; контурные линии вынесены в отдельные слои для настольной и мобильной версий.
- Адреса страниц соцсетей в макете отсутствуют, поэтому иконки не ведут на вымышленные ссылки.
